# Casa de Leilões - LeiloesTDSat

## Sobre o Projeto

Sistema informatizado desenvolvido para uma casa de leilões, com o objetivo de automatizar e gerenciar as rotinas do negócio. O sistema permite o cadastro de produtos, clientes e lances, facilitando o controle e a organização dos leilões realizados pela empresa.

## Tecnologias Utilizadas

- **Java** — Linguagem de programação principal utilizada no desenvolvimento do sistema
- **MySQL** — Sistema de gerenciamento de banco de dados relacional utilizado para armazenamento das informações
- **NetBeans IDE** — Ambiente de desenvolvimento integrado utilizado para criação do projeto

## Como Executar

1. Importe o banco de dados MySQL disponível na pasta do projeto
2. Abra o projeto no NetBeans IDE
3. Configure a conexão com o banco de dados
4. Execute o projeto
